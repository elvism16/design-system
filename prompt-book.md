# Prompt Book

```
Arbeite zunächst ausschließlich lesend.

1. Suche im Repository nach bestehenden Komponenten oder Patterns mit den Namen
   Banner, Alert, Notice oder vergleichbaren Bezeichnungen. Prüfe auch die Stories.
   Klassifiziere den Figma-Banner danach als neu, bestehend oder zu überarbeiten.

2. Untersuche diesen Figma-Node mit Figma MCP:
   https://www.figma.com/design/5UJoWRZJ7iqmfixMGp3F9Z/TECE-Design-System?node-id=5679-7317&t=odEcgyw9BOKTaAR5-1

3. Erfasse nur tatsächlich erkennbare Varianten, Zustände, Verhalten,
   responsive Regeln sowie Figma Variables, Collections, Modi und Aliase.
   Erfinde keine Varianten, Werte, Token-Namen oder Verhaltensweisen.

4. Vergleiche die Figma Variables mit den vorhandenen Token-JSONs im Repository.
   Erstelle eine Tabelle mit:
   Figma-Eigenschaft | Figma Variable/Collection/Mode/Wert |
   möglicher JSON-Pfad | erzeugte CSS-Variable |
   Status (Match/Abweichung/kein Mapping) | offene Entscheidung

Figma Variables sind die Quelle für gestaltete Variablen und Modi.
Die Repository-JSONs bleiben die freigegebene Quelle für Code-Token-Dateien.
Der bestehende Token-Build darf nicht entfernt oder verändert werden.

Erstelle daraus einen Entwurf der Implementierungsspezifikation.
Ändere keine Dateien und warte auf Freigabe.
```
